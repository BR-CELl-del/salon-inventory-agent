# Salon Inventory AI Trial

This is a simple browser-based prototype for a salon inventory and booking estimation dashboard.

## Open locally

Open `index.html` in a browser to try the app.

## What it shows

- bookings by service
- product stock levels
- estimated usage by service
- low-stock alerts
- simple AI suggestions

## Use case

This is meant to model how a salon could estimate product demand from service bookings, even when product usage is estimated rather than fixed.
